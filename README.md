# Digby

Native macOS app built with SwiftUI.

## Requirements

- macOS 15.0+
- Xcode 16+

## Getting started

```bash
open Digby.xcodeproj
```

Or build from the command line:

```bash
xcodebuild -project Digby.xcodeproj -scheme Digby -configuration Debug build
```

Run tests:

```bash
xcodebuild -project Digby.xcodeproj -scheme Digby test
```
